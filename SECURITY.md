# Security Policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue or pull request for them.

1. Go to this repository's **Security** tab.
2. Click **Report a vulnerability** to open a private security advisory.
3. Describe the problem, the steps to reproduce it, and the impact you expect.

We will respond as soon as we can and work with you on a fix before anything is disclosed publicly.

## Untrusted input

Journey labels are treated as untrusted input. If you find a way a crafted label could cause harm, please report it through the private advisory process above.
